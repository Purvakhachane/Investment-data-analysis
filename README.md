# Investment Data Analysis

## Project Overview
This project analyzes investment preferences and financial behavior using Python and data visualization techniques.

The analysis was performed using Google Colab with libraries such as pandas, matplotlib, and seaborn.

---

## Objectives
- Understand dataset structure
- Analyze gender distribution
- Generate descriptive statistics
- Identify preferred investment avenues
- Analyze investment reasons
- Explore savings objectives
- Study investment information sources
- Calculate investment duration
- Analyze expectations from investments
- Perform correlation analysis

---

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

---

## Dataset Features
The dataset includes:
- Gender
- Age
- Investment avenues
- Mutual funds
- Equity market
- Government bonds
- Fixed deposits
- Gold investment
- Savings objectives
- Investment duration
- Information sources
- Expectations from investments

---

## Key Insights
- Mutual funds and equity markets are highly preferred investment options.
- Participants mainly invest for financial growth and security.
- Internet and financial advisors are common information sources.
- Most investors expect stable and higher returns from investments.
